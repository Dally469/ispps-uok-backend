# ISPPS Backend

FastAPI service for the **Intelligent Student Performance Prediction System** —
the academic backend for a final-year project. Predictions are generated by an
**in-house scikit-learn model trained on the project's own data**.
No third-party LLM is used.

---

## Stack

| Layer       | Choice                                   |
|-------------|------------------------------------------|
| Framework   | FastAPI 0.115, Uvicorn                   |
| ORM         | SQLAlchemy 2 (async) + asyncpg           |
| Database    | PostgreSQL 14+                           |
| Auth        | JWT (HS256) + HTTP-only `auth_token` cookie |
| ML          | scikit-learn 1.5 (RandomForest x2)       |

## Quick start

```powershell
# 1. Create + activate a virtualenv
python -m venv venv
.\venv\Scripts\Activate.ps1

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure the environment
copy .env.example .env
# edit .env — set DATABASE_URL and JWT_SECRET

# 4. Provision the database
psql $env:DATABASE_URL -f db/schema.sql
psql $env:DATABASE_URL -f db/seed.sql

# 5. Train the prediction model (one-off, repeat after data changes)
python -m ml.train

# 6. Run the API
uvicorn app.main:app --reload --port 8001
```

Interactive docs: `http://127.0.0.1:8001/docs`.

## Prediction endpoints

| Method | Path                          | Purpose                                      |
|--------|-------------------------------|----------------------------------------------|
| GET    | `/api/predictions`            | List/filter saved predictions                |
| POST   | `/api/predictions/generate`   | Run the ML model for a student (+ course)    |
| POST   | `/api/predictions`            | Manual create (admin/backfill)               |
| POST   | `/api/insights/summary`       | Performance summary (rule-based, ML features)|
| POST   | `/api/insights/study-plan`    | Personalised study plan                      |
| GET    | `/api/insights/risk-scan`     | Bulk at-risk scan for a school               |

All inputs/outputs are documented in `/docs`.

## Machine learning

See [`ml/README.md`](ml/README.md). Summary:

- Two heads: `RandomForestRegressor` for the predicted grade,
  `RandomForestClassifier` for the pass/fail probability.
- 15 engineered features per (student, course) — averages, std-dev,
  per-assessment-type breakdowns, attendance metrics, credit hours.
- Train with `python -m ml.train`, inspect metrics with
  `python -m ml.evaluate`.

## Testing the prediction endpoint

After training the model and logging in as a lecturer/admin:

```bash
curl -X POST http://127.0.0.1:8001/api/predictions/generate \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"student_id": "<uuid>", "course_id": "<uuid>"}'
```

Response contains `predicted_grade`, `pass_probability`, `risk_level`,
`factors`, `recommendations`, and a `summary`.
